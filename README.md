# Vehicle Oracle — Full-Stack Used Car Price Predictor

Full-stack version of the AI used car price predictor: a machine learning model (XGBoost, R² 0.9858, MAE $1,146, 0.3s prediction) with a web frontend and backend.

## Stack

- Frontend: React (`react-frontend/`)
- Backend: Python / Machine Learning (XGBoost, Scikit-learn, Pandas)
- Live demo and model details: see `Car_Price_Predictor` repository
